# Общий конфиг tmux

Исходник для всех устройств: `tmux/tmux.conf` в репозитории Neovim.
Установленная копия: `~/.tmux.conf`. Конфиг входит в общий набор вместе
с Neovim, WezTerm и Termux:Launcher и проверяется при их синхронизации.

Префикс — Ctrl+A: нажать, отпустить, затем следующую клавишу.

| После Ctrl+A | Действие |
|---|---|
| Стрелки | Перейти в соседнюю панель |
| Tab | Следующая панель |
| y | Включить или выключить синхронный ввод текущего окна |
| m | Включить или выключить мышь, включая прокрутку истории |
| S | Разделить панель горизонтально |
| \| | Разделить панель вертикально |
| c | Новое окно |
| n / p | Следующее / предыдущее окно |
| r | Перечитать `~/.tmux.conf` |

При включённом sync справа в строке состояния показывается красный `SYNC`.
Мышь по умолчанию выключена, как в сохранённом пользовательском конфиге.
Все остальные сочетания и настройки находятся в исходнике.

Проверка на отдельном сервере без рабочих сессий:

```sh
python3 tests/check_tmux.py
```

Тест проверяет загрузку/перечитывание, префикс, привязки навигации, sync
и переключение мыши. Физический ввод через WezTerm или клавиатуру телефона
требует отдельной ручной проверки.

При установке сравнивать контрольные суммы исходника и рабочей копии,
проверять альтернативный `~/.config/tmux/tmux.conf` и локальные правки.
Существующую конфигурацию предварительно резервировать. В работающем сервере
новые настройки подключаются без перезапуска сессий:

```sh
tmux source-file ~/.tmux.conf
tmux show-options -gv prefix
tmux list-keys -T prefix
```

Ожидаемый префикс — `C-a`, действие `y` — `synchronize-panes`.
