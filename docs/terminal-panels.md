# Терминальные панели

В Normal mode **Пробел t** открывает меню:

| Сочетание | Действие |
|---|---|
| Пробел tt | Показать / скрыть терминальную панель, как Ctrl+` / F7 |
| Пробел th | Разделить активную панель горизонтально |
| Пробел tv | Разделить активную панель вертикально |
| Пробел tn | Новая сессия в текущей терминальной панели, с сохранением её размеров и zoom |
| Пробел tc | Закрыть текущую сессию терминала или панель редактора |
| Пробел tC | Закрыть остальные консоли, оставив текущую |
| Пробел tq | Закрыть все консоли |

В редакторе th/tv показывают тот же файл в новом окне. В терминале создают
новую оболочку в соседней панели; для показа обеих панелей desktop zoom снимается.
Мобильный профиль сохраняет автоматический zoom новой терминальной панели.
При закрытии сессии tc показывает другую скрытую сессию в той же панели;
если такой нет, закрывает панель. Файловые буферы сохраняются при закрытии
отдельного окна редактора. Для последнего окна закрывается текущий буфер
с обычным подтверждением несохранённых изменений, без выхода из Neovim.

Массовое закрытие tC/tq относится к обычным консолям F7/F8, включая скрытые
сессии. Отдельная панель Codex и служебные терминалы вроде lazygit не входят
в этот список. tC вызывается из той консоли, которую нужно оставить.
Эти команды завершают процессы оболочек; tt лишь прячет панель.

**Alt+t свободен** во всех режимах и передаётся терминальному приложению.
Чтобы открыть меню из терминального ввода, сначала нажмите **Ctrl+Shift+←**
или **Ctrl+Space** для Normal mode. Пробел в командной строке не перехватывается.
Дополнительные прежние команды AstroNvim остаются под **Пробел T**.

**Ctrl+Shift+` / F8** выбирает сессию с сохранением панели и zoom.
Отмена сохраняет прежнюю сессию. Клик по сессии в Winbar использует тот же путь;
повторный клик по активной сессии не закрывает её. **Alt+z / Ctrl+Shift+↑**
разворачивает панель или восстанавливает раскладку окон.

Ctrl+` и Ctrl+Shift+` передаются настройками WezTerm как F7 и F8.
На телефоне доступны F7/F8 из настроенной экранной клавиатуры.
Мобильные профили Termux и Nix-on-Droid сохраняют автоматический zoom терминала.

Окно запоминает назначение: терминал или редактор. Выбор файла из терминала
через таббар либо Пробел bb открывает его в окне редактора и переводит туда
фокус. Если подходящего редактора нет, создаётся новое окно. Выбор терминала
из редактора переводит в терминальную панель. Средняя кнопка таббара по-прежнему
закрывает буфер с обычным подтверждением для несохранённых изменений.
Прямая смена буфера и сторонние pickers также проверяются после обработки события.
Служебные окна Neo-tree и временные picker-окна не получают роль редактора.

Запущенный внутри bash `vim` остаётся приложением того же PTY. Такая вложенная
сессия не меняет назначение внешней терминальной панели. Завершение оболочки
и закрытие панели не ограничиваются; запрета на создание обычных splits нет.
Роль нового split определяется после назначения его начального буфера.

Snacks Zoom отображает копию буфера в плавающем окне. Владельцем ToggleTerm-сессии
остаётся исходный split; копия не записывается как отдельная открытая сессия.
Выбор сессии не перезапускает оболочку и не отправляет ей команды.

Проверка установленных ToggleTerm и Snacks с настоящими PTY без загрузки AstroNvim:

```bash
nvim --headless -u NONE -i NONE -l tests/check_terminal_panels.lua
NVIM_PROFILE=nix-on-droid nvim --headless -u NONE -i NONE -l tests/check_terminal_panels.lua
nvim --headless -u NONE -i NONE -l tests/check_terminal_actions.lua
```

Вторая команда проверяет логику мобильного профиля на локальном Neovim;
она не заменяет нативную проверку на телефоне. Клавиатурная проверка полной
конфигурации — `tests/check_keys.py`; запускать с изолированными XDG-каталогами
и `NVIM_UNIVERSAL_TEST=1`, как описано в `docs/universal.md`.
