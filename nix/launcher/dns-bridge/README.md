# Android DNS Bridge

Минимальный Android-помощник для получения DNS **активной сети приложения**.
Не требует root, отладки, Shizuku, геолокации, доступа к файлам или Интернету.
Единственное разрешение — обычное `ACCESS_NETWORK_STATE`. Нет службы,
автозапуска, SDK аналитики, HTTP-сервера или внешних библиотек.

APK содержит Activity для просмотра параметров и экспортированный
BroadcastReceiver, возвращающий снимок сети по явному запросу. Эти параметры
доступны любому Android-приложению с обычным разрешением чтения состояния сети;
помощник не выполняет команды и не изменяет настройки телефона.

## Установка и проверка

Установить APK обычным установщиком Android и один раз открыть приложение.
Включать отладку не нужно. В случае VPN со списком приложений включить
помощник в тот же список, что и Launcher: иначе они могут видеть разные сети.

После установки проверен реальный ответ на телефоне: DNS `192.168.0.1`,
поисковый домен `lan`, Wi-Fi; Private DNS выключен. Запрос через `am`
работает из Nix без отладки.

```bash
android-dns --json  # только сведения, без изменения файлов
android-dns         # предпросмотр resolv.conf
```

Команда `android-dns` описана в декларации `nix/launcher/flake.nix`.
До применения обновлённого профиля доступен запуск через Python:
`python3 ~/.config/nvim/nix/launcher/dns-bridge/android_dns.py --json`.

## Генерация и обновление

По выбору пользователя обновление выполняется **при запуске интерактивной
оболочки** и вручную командой **`dns-sync`**. Таймера, наблюдателя сети
и фонового процесса нет. После смены сети в открытой сессии нужно выполнить
`dns-sync`; иначе сохранится предыдущий снимок.

Функция в `interactive-shell.sh` запускает:

```bash
android-dns --output "$HOME/.local/state/android-dns/resolv.conf"
```

При успешном запросе файл обновляется атомарно, только если содержимое
изменилось. Сбой запроса сообщает об ошибке и сохраняет предыдущий файл.

Системный модуль `system.nix` связывает `/etc/resolv.conf` с этим файлом
через `config.user.home`, без абсолютного пути конкретного телефона.
Он подключается как `android-dns.nix` из системной декларации
`~/.config/nix-on-droid/nix-on-droid.nix`. Для переключения сначала нужен
успешно сгенерированный файл. `.local/state` сохраняется между запусками.
Настройки внутри `/nix/store` вручную не редактируются.
При первом применении переключается только ссылка `/etc/resolv.conf`
на генерируемый файл; полная системная активация Nix не запускается.
Модуль закрепляет тот же источник для будущих системных активаций.

Обычные DNS IPv4/IPv6 и поисковые домены переносятся из Android. В resolv.conf
попадают до трёх уникальных серверов и до шести поисковых доменов.

**Private DNS:** прямой resolv.conf не воспроизводит шифрованный DNS Android.
При активном Private DNS генерируется блокирующая конфигурация с localhost
и возвращается ошибка; прежние адреса и публичные fallback-серверы не
используются. При отсутствии сети генерируется такая же блокирующая конфигурация.
После восстановления сети нужно повторить `dns-sync`.
Этот режим подходит для обычного DNS, включая доступные приложению VPN-DNS.
Для сохранения поведения Private DNS потребуется системный DNS-прокси.

Изменение собственных резолверов приложений (DoH, браузерный DNS и т. п.)
не входит в задачу. Поддержку Android Private DNS нельзя считать проверенной
простым успешным запросом публичного имени.

## Сборка и ключ

Исходники Java используют только публичные API Android. Сборка без Gradle:
JDK 17, платформа Android 35, build-tools 35.0.0. Точные хеши SDK-архивов
и Docker-образ JDK записаны в `build-inputs.json`. Архивы:

- `https://dl.google.com/android/repository/platform-35_r02.zip`
- `https://dl.google.com/android/repository/build-tools_r35_linux.zip`

`build-apk.sh` принимает пути через переменные `ANDROID_JAR`,
`ANDROID_BUILD_TOOLS`, `DNS_BRIDGE_KEYSTORE`, `DNS_BRIDGE_KEY_PASSWORD`,
`DNS_BRIDGE_BUILD_DIR`. Каталог сборки и постоянный ключ подписи должны
оставаться вне Git. В текущей рабочей копии они находятся в игнорируемых
`.reports/android-dns/` и `.backups/android-dns/`. Ключ нужно сохранить:
без него следующие версии не установятся поверх этого APK.

APK собран с явным `debuggable=false`; подписи v1/v2/v3 проверены
`apksigner verify`. APK установлен пользователем; чтение DNS через BroadcastReceiver
проверено на телефоне. Смена Wi-Fi/VPN автоматически не отслеживается.

Проверки клиента: `python3 tests/check_android_dns.py` из корня репозитория.
Они не обращаются к сети или телефону и не записывают в `/etc`.
